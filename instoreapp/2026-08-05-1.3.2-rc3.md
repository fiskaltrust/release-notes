# InStore App 1.3.2-rc3
[![Static Badge](https://img.shields.io/badge/milestone-v1.3.2--rc3-green?logo=github)](https://github.com/fiskaltrust/fiskaltrust-instore-app/milestone/12)

<!--truncate-->

## Nexi payment support (SoftPOS)

Nexi is now supported as a payment provider. The integration is based on the Nexi **MyPayments** SoftPOS app, so no additional payment terminal is required - the phone or Android device itself acts as the card reader.

Supported actions are **payment**, **refund** and **cancel**, all triggered directly from the InStore App.

_Affected issue(s):_ [#728](https://github.com/fiskaltrust/fiskaltrust-instore-app/issues/728)

---

## SumUp payment support

SumUp is now supported as a payment provider. Payments are processed through the **SumUp app** (PaymentSwitch), which means a SumUp Solo or Solo Light reader can be used without any additional integration effort.

If the **merchant API key** is configured in the settings, the InStore App additionally uses the SumUp cloud API to enable:

- **refund**
- **cancel**
- **improved payment receipts** with the full transaction details

Without the API key, only the payment action is available. See the feature matrix in the docs for the exact scope.

_Affected issue(s):_ [#739](https://github.com/fiskaltrust/fiskaltrust-instore-app/issues/739)

## Official GP tom certification

The InStore App has successfully passed the official **GP tom certification process** and is now listed as a certified partner solution: https://www.gptom.com/en/fiskaltrust-instoreapp/

This means the GP tom App2App integration is approved for production use beginning with v1.3.2-rc3.

_Affected issue(s):_ [#112](https://github.com/fiskaltrust/fiskaltrust-instore-app/issues/112)
