# Middleware 1.3.86
[![Static Badge](https://img.shields.io/badge/milestone-v1.3.86-green?logo=github)](https://github.com/fiskaltrust/middleware/milestone/18?closed=1)

This release makes the automatic Epson RT printer reboot after a successful daily closing,
which was introduced always-on in 1.3.85,
opt-in via a new SCU configuration flag.
<!--truncate-->

:::caution

Customers in Austria and France should continue to use version 1.2 of the middleware.
We are working on a unified version for all markets.

:::

## 🇮🇹 Breaking Change: Automatic Epson RT printer reboot after daily closing is now opt-in ([fiskaltrust/middleware#702](https://github.com/fiskaltrust/middleware/pull/702))

In 1.3.85 the Epson RT printer was rebooted automatically after every successful daily closing (ZReport) to work around printers that occasionally get stuck during the day.
Because this behavior is not desirable for every deployment,
it is now opt-in and disabled by default.

To keep the automatic post-closing reboot,
set the new `ForceRebootAfterDailyClosing` flag to `true` in the Epson RT printer SCU configuration.

Deployments that were relying on the always-on behavior introduced in 1.3.85 will no longer reboot the printer after a daily closing until this flag is enabled.
The manual reboot triggered from the POS via the Zero Receipt flag (`0x0000_0040_0000_0000`) is unaffected and continues to work as before.

### Affected packages:
- _fiskaltrust.Middleware.SCU.IT.EpsonRTPrinter_
