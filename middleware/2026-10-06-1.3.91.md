# Middleware 1.3.91
[![Static Badge](https://img.shields.io/badge/milestone-v1.3.91-green?logo=github)](https://github.com/fiskaltrust/middleware/milestone/23?closed=1)

With this release, support for the Swissbit Hardware TSE V2 devices in Germany is now generally available.
<!--truncate-->

:::caution

Customers in Austria and France should continue to use version 1.2 of the middleware.
We are working on a unified version for all markets.

:::

## 🇩🇪 Feature: Support for Swissbit Hardware TSE V2 ([fiskaltrust/middleware#798](https://github.com/fiskaltrust/middleware/pull/798))

The German Swissbit hardware SCU now supports the new **Swissbit Hardware TSE V2** devices.
We updated the underlying Swissbit TSE library to the latest version (v6.0.1),
which enables the Middleware to work with the new generation of Swissbit hardware TSEs.
Existing TSE V1 devices continue to work unchanged.

### Affected packages:
- _fiskaltrust.Middleware.SCU.DE.Swissbit_
