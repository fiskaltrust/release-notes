# Middleware 1.3.87
[![Static Badge](https://img.shields.io/badge/milestone-v1.3.87-green?logo=github)](https://github.com/fiskaltrust/middleware/milestone/19?closed=1)

This release adds support for the new Swissbit Hardware TSE V2 devices in Germany and corrects the spelling of the `DisableSSLValidation` configuration parameter in the Italian Custom RT Server SCU.
<!--truncate-->

:::caution

Customers in Austria and France should continue to use version 1.2 of the middleware.
We are working on a unified version for all markets.

:::

## 🇩🇪 Feature _\[Release Candidate]_: Support for Swissbit Hardware TSE V2 ([fiskaltrust/middleware#633](https://github.com/fiskaltrust/middleware/pull/633))

The German Swissbit hardware SCU now supports the new **Swissbit Hardware TSE V2** devices.
We updated the underlying Swissbit TSE library to the latest version (v6.0.0),
which enables the Middleware to work with the new generation of Swissbit hardware TSEs in addition to the existing V1 devices.

### Affected packages:
- _fiskaltrust.Middleware.SCU.DE.Swissbit_

## 🇮🇹 Bug Fix: Corrected spelling of the `DisableSSLValidation` configuration parameter ([fiskaltrust/middleware#713](https://github.com/fiskaltrust/middleware/pull/713))

The configuration parameter to disable SSL validation in the Custom RT Server SCU was previously misspelled as `DisabelSSLValidation`.
This has been corrected to `DisableSSLValidation`.

### Affected packages:
- _fiskaltrust.Middleware.SCU.IT.CustomRTServer_
